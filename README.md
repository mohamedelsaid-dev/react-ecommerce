# 🛒 Elsaid Online Store

A modern and responsive E-commerce web application built with **React.js**, focused on providing a clean shopping experience with product browsing, search, categories, favorites, shopping cart, product details, and responsive UI.

## 🚀 Live Demo

🔗 [View Live Demo](https://react-ecommerce-cyan-pi.vercel.app/)

## 📸 Project Overview

Elsaid Online Store is a front-end E-commerce project built to demonstrate practical React development skills, reusable components, state management, API integration, client-side routing, and responsive web design.

The application uses the DummyJSON API to fetch and display product data dynamically.

## ✨ Features

- 🛍️ Browse products
- 🔎 Search products
- 📂 Browse products by category
- 📄 View detailed product information
- 🛒 Add products to the shopping cart
- ➕ Increase and decrease product quantity
- 🗑️ Remove products from the cart
- ❤️ Add and manage favorite products
- ⭐ Display product ratings
- 🖼️ Responsive hero image slider
- 🔗 Client-side navigation with React Router
- 📱 Fully responsive design for desktop, tablet, and mobile
- ⚡ Dynamic product data using REST API
- 🎨 Clean and modern user interface

## 🛠️ Technologies

## 🧠 React Concepts Used

This project demonstrates practical usage of:

- React Functional Components

- Reusable components

- Component-based architecture
